# VP Nest Website

A polished one-page website for VP Nest | THE99CREW with business-specific content, contact form handling, embedded Google Maps, and Razorpay-ready booking structure.

## Run locally

Open the project folder in a browser or serve it with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Notes

- Contact form opens the user’s mail client for delivery.
- Razorpay integration is prepared in the booking section via a placeholder checkout button.
